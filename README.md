# HTML & CSS Assignments — Muhammad Saif Khan

This folder contains standalone HTML pages based on the numbered HTML/CSS topics (06–45) in the referenced repository, plus supporting pages and an index.

## How to open
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Click an assignment filename to preview it.
4. Most assignments are standalone HTML files with their CSS inside a `<style>` block. `styles.css` is included as a shared reference stylesheet.

## Notes
- The pages are beginner-friendly examples made for practice and should be reviewed against the exact instructions your instructor provided.
- The multi-page exercise includes `20-about.html`, `20-courses.html`, and `20-contact.html`.
- Forms are front-end demonstrations; they do not send or save submitted data.
- Placeholder gallery images need an internet connection to load.
- Add your own required class/roll number and check the assignment requirements before submitting.
